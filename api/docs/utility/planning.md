# Planejamento

![Painel de planejamento](../assets/img/financial-plan.png)

*Painel de Planejamento: renda, contas fixas, dívidas e metas.*

## Configurar a renda mensal

1. No painel, selecione **Editar renda**.
2. Informe sua **Renda mensal** esperada.
3. Selecione **Salvar**.

A renda fica guardada até você mudar de novo — não precisa reconfigurar todo mês.

## Como ler o painel

| Card | O que mostra |
| --- | --- |
| Renda mensal | o valor configurado |
| Contas fixas do mês | soma das despesas do mês corrente (inclui as contas fixas recorrentes) |
| Sobra do mês | renda menos contas fixas menos a próxima parcela de cada dívida ativa |
| Dívidas ativas | cada financiamento com saldo devedor, e o valor/data da próxima parcela em aberto |
| Metas ativas | cada meta ainda não alcançada, com barra de progresso |

::: primary
O painel só mostra os números — ele **não decide** quanto colocar em cada dívida ou meta. Use a sobra do mês como referência e distribua manualmente lançando aportes nas metas e, se quiser antecipar, pagando parcelas extras dos financiamentos.
:::

## Contas fixas

Acesse **Contas fixas** a partir do painel para ver as ocorrências geradas pelas suas transações recorrentes, ainda não pagas (status "Previsto"). Selecione **Marcar como paga** quando o dinheiro realmente saiu da conta.

Veja [Transações, transferências e contas fixas](./transactions.md#repetir-automaticamente-conta-fixa) para cadastrar uma nova conta fixa.
