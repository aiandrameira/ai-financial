# Orçamento

![Tela de orçamento](../assets/img/list-budget.png)

*Cartões de orçamento por categoria, com barra de progresso.*

## Navegar entre meses

Use as setas ao lado do mês exibido para ver orçamentos passados ou planejar o mês seguinte. O botão **Hoje** volta para o mês atual.

## Cadastrar um orçamento

1. Selecione o botão de cadastrar orçamento.
2. Escolha a categoria de despesa (só aparecem categorias que ainda não têm orçamento naquele mês).
3. Informe o **Valor planejado**.
4. Selecione **Salvar**.

## Como ler o cartão

Cada cartão mostra o valor realizado (soma das despesas da categoria, naquele mês) contra o valor planejado, com uma barra de progresso:

- verde: dentro do planejado;
- amarelo ("Perto do limite"): 80% ou mais do planejado já realizado;
- vermelho ("Orçamento estourado"): realizado igual ou maior que o planejado.

## Editar e apagar

Clique no cartão para editar o valor planejado. A categoria e o mês não podem ser trocados depois de criado — apague e cadastre de novo se precisar mudar de categoria.
