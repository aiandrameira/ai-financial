# Contas

![Tela de contas](../assets/img/list-account.png)

*Lista de contas com saldo atual e projetado.*

## O que a tela mostra

| Coluna | Significado |
| --- | --- |
| Tipo | badge de Corrente, Poupança ou Carteira |
| Saldo atual | soma das transações já concluídas |
| Saldo projetado | saldo atual + transações previstas/pendentes ainda não concluídas |

O saldo projetado ajuda a ver o impacto de contas fixas ainda não pagas e transações futuras já lançadas.

## Cadastrar

1. Selecione o botão de cadastrar.
2. Preencha **Nome**, **Tipo**, **Instituição** (opcional), **Saldo inicial**, cor e ícone (opcionais).
3. Selecione **Cadastrar**.

## Editar

Clique na linha da conta, selecione **Editar**, altere os campos e **Salvar**.

::: primary
Corrigir o **Saldo inicial** depois de já existirem transações muda o saldo atual e projetado imediatamente — use com cuidado, só para corrigir um valor errado no cadastro original.
:::

## Arquivar e restaurar

Use **Arquivar** em vez de excluir. Uma conta arquivada:

- some dos seletores de conta ao lançar uma transação nova;
- continua aparecendo no histórico de transações já lançadas;
- pode ser restaurada a qualquer momento pelo botão **Restaurar**.
