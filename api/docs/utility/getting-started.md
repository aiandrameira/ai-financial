# Começando no AI Financial

Este guia considera que você nunca utilizou o AI Financial. Siga as etapas na ordem indicada. Os nomes em **negrito** correspondem a textos, menus ou botões visíveis na tela.

## Antes de começar

Você precisa de:

- endereço do app AI Financial;
- navegador atualizado.

::: primary
O AI Financial ainda não tem login — é um app de uso individual, sem tela de acesso. Isso é uma fase futura (veja [Próximas atualizações](../introduction.md#proximas-atualizacoes)).
:::

### Termos usados no sistema

| Termo | Significado simples |
| --- | --- |
| Conta | onde o dinheiro fica: corrente, poupança ou carteira |
| Transação | qualquer lançamento de receita ou despesa |
| Transferência | movimento entre duas contas suas — não é receita nem despesa |
| Conta fixa | uma transação que se repete automaticamente (recorrência) |
| Fatura | o agrupamento mensal das compras de um cartão de crédito |
| Saldo devedor | quanto ainda falta pagar de um financiamento |
| Sobra do mês | renda menos contas fixas menos parcelas mínimas de dívida, no painel de Planejamento |

## 1. Abrir o app

1. Abra o navegador.
2. Digite o endereço do AI Financial na barra superior.

### Resultado esperado

::: success
O app abre na tela **Contas**, ainda vazia se for o primeiro acesso.
:::

## 2. Cadastrar a primeira conta

1. Na tela **Contas**, selecione o botão de cadastrar.
2. Em **Nome**, informe, por exemplo, "Conta principal".
3. Em **Tipo**, escolha Corrente, Poupança ou Carteira.
4. Em **Saldo inicial**, informe o saldo atual dessa conta hoje.
5. Selecione **Cadastrar**.

### Resultado esperado

A conta aparece na tabela com **Saldo atual** e **Saldo projetado** iguais ao saldo inicial informado.

## 3. Cadastrar categorias (se precisar de mais)

O app já vem com categorias padrão de receita e despesa. Para adicionar uma:

1. Abra **Categorias** no menu lateral.
2. Selecione o botão de cadastrar.
3. Escolha **Tipo** (Receita ou Despesa), informe o **Nome** e, se quiser, um ícone e cor.
4. Selecione **Salvar**.

::: warning
Uma transação só pode usar uma categoria do mesmo tipo (receita com receita, despesa com despesa).
:::

## 4. Lançar a primeira transação

1. Abra **Transações**.
2. Selecione o botão de cadastrar.
3. Escolha **Tipo** (receita ou despesa) e a origem (**Conta** ou **Cartão**).
4. Selecione a conta e a categoria.
5. Informe o **Valor** e a **Data**.
6. Selecione **Salvar**.

### Resultado esperado

::: success
A transação aparece na lista, e o saldo da conta em **Contas** já reflete o novo valor.
:::

## 5. Cadastrar uma conta fixa (transação recorrente)

Use para uma despesa ou receita que se repete todo mês — aluguel, assinatura de streaming, salário.

1. Ao cadastrar uma transação de **Conta** (não de cartão), ative **Repetir automaticamente**.
2. Escolha a **Frequência** (diária, semanal, mensal ou anual) e o intervalo.
3. Selecione **Salvar**.
4. Depois, abra **Planejamento → Contas fixas** para ver as ocorrências geradas e marcá-las como pagas quando o dinheiro realmente saiu.

## 6. Cadastrar um cartão de crédito

1. Abra **Cartões**.
2. Selecione o botão de cadastrar.
3. Informe **Nome**, a **Conta** que paga a fatura, **Limite**, **Dia de fechamento** e **Dia de vencimento**.
4. Selecione **Salvar**.
5. Ao lançar uma transação, escolha origem **Cartão** em vez de Conta para que ela entre na fatura do mês certo.

## 7. Definir um orçamento

1. Abra **Orçamento**.
2. Selecione o botão de cadastrar orçamento.
3. Escolha a categoria de despesa e o valor planejado para o mês.
4. Selecione **Salvar**.

O cartão do orçamento mostra o valor realizado (soma das despesas da categoria naquele mês) contra o planejado, com aviso visual perto do limite ou ao estourar.

## 8. Cadastrar um financiamento

1. Abra **Financiamentos**.
2. Selecione o botão de cadastrar.
3. Informe **Nome**, **Tipo**, **Valor financiado**, **Taxa de juros**, **Número de parcelas**, **Data de início** e a **Conta** que paga.
4. Selecione **Salvar**.

::: warning
Depois de cadastrado, o valor financiado, a taxa e o número de parcelas não podem mais ser alterados — confira antes de salvar.
:::

5. Abra o financiamento para ver a tabela de parcelas e use **Pagar parcela** quando ela for paga de verdade — isso lança a despesa na conta automaticamente.

## 9. Cadastrar uma meta de economia

1. Abra **Metas**.
2. Selecione o botão de cadastrar.
3. Informe **Nome**, **Valor-alvo** e, se quiser, uma **Data-alvo**.
4. Selecione **Salvar**.
5. Abra a meta e use **Registrar aporte** sempre que guardar dinheiro para ela.

## 10. Cadastrar um investimento

1. Abra **Investimentos**.
2. Selecione o botão de cadastrar.
3. Informe **Nome** e **Tipo** (renda fixa, ação, FII, tesouro, cripto ou fundo).
4. Selecione **Salvar**.
5. Abra o ativo e registre um **movimento** (compra, venda, aporte, resgate ou dividendo) e, periodicamente, uma **cotação manual** para manter o valor atual atualizado.

## 11. Cadastrar um bem

Use para patrimônio fora do fluxo de transações — um imóvel ou veículo, por exemplo.

1. Abra **Bens**.
2. Selecione o botão de cadastrar.
3. Informe **Nome**, **Tipo**, **Valor de compra**, **Valor atual** e **Data de aquisição**.
4. Selecione **Salvar**.

## 12. Configurar o Planejamento

1. Abra **Planejamento**.
2. Selecione **Editar renda**, informe sua **Renda mensal** e selecione **Salvar**.

### Resultado esperado

::: success
O painel mostra a renda, as contas fixas do mês, a lista de dívidas ativas (com a próxima parcela) e as metas ativas — e, em destaque, a sobra do mês.
:::

O painel **não sugere** como dividir a sobra entre dívidas e metas — essa decisão é sua.

## Se algo der errado

Antes de pedir ajuda, anote:

- tela em que o problema ocorreu;
- botão acionado;
- mensagem apresentada;
- nome do registro envolvido.

## Regras importantes para quem está começando

| Pode | Não pode |
| --- | --- |
| arquivar uma conta ou cartão sem perder o histórico | excluir uma conta com transações — arquive em vez disso |
| editar o valor financiado antes de salvar | alterar valor, juros ou parcelas de um financiamento já cadastrado |
| pagar uma parcela ou fatura só uma vez | pagar de novo uma parcela ou fatura já marcada como paga |
| aguardar a mensagem de sucesso antes de continuar | clicar várias vezes em Salvar durante o carregamento |
| usar Conta fixa para algo que realmente se repete todo período | usar recorrência em transações de cartão (hoje só funciona para conta) |
