# Cartões de crédito

![Tela de cartões](../assets/img/list-credit-card.png)

*Lista de cartões de crédito.*

## Cadastrar um cartão

1. Selecione o botão de cadastrar.
2. Informe **Nome**, a **Conta** que paga a fatura, **Limite**, **Dia de fechamento**, **Dia de vencimento** e, opcionalmente, a **Bandeira**.
3. Selecione **Salvar**.

O dia de fechamento define a partir de quando uma compra passa a contar para a fatura do mês seguinte.

## Acompanhar faturas

Abra o cartão para ver suas faturas. A fatura do mês atual é criada automaticamente na primeira vez que você a acessa ou lança uma compra naquele período — não precisa cadastrá-la manualmente.

## Pagar uma fatura

1. Abra a fatura.
2. Selecione **Pagar fatura**.
3. Confirme a data de pagamento (ou deixe a data de hoje).

Pagar a fatura lança uma despesa real na conta associada ao cartão, pelo valor total da fatura, e marca a fatura como paga. Uma fatura já paga não pode ser paga de novo.

## Arquivar e restaurar

Igual às contas: **Arquivar** remove o cartão dos seletores de novas transações sem apagar o histórico; **Restaurar** desfaz.
