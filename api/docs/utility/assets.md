# Bens

![Tela de bens](../assets/img/list-asset.png)

*Lista de bens (patrimônio).*

Bens representam patrimônio que não passa pelo fluxo normal de transações — um imóvel ou veículo, por exemplo — usados para compor a visão de patrimônio líquido junto com contas, investimentos e dívidas.

## Cadastrar

1. Selecione o botão de cadastrar.
2. Informe **Nome**, **Tipo** (imóvel, veículo ou outro), **Valor de compra**, **Valor atual** e **Data de aquisição**.
3. Selecione **Salvar**.

## Manter atualizado

Edite o bem periodicamente para atualizar o **Valor atual** conforme ele se valoriza ou deprecia — diferente de contas e investimentos, esse valor não é calculado automaticamente, então precisa ser ajustado manualmente.
